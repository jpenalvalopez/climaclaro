# Roadmap de ClimaClaro

## Estado actual

ClimaClaro ya está desplegado y funcionando.

Tiene:
- Web pública.
- Wizard.
- Calendario.
- Base de datos propia.

## Fase 1 — Estabilidad y documentación

Objetivo:
- Documentar proyecto.
- Evitar errores con Codex.
- Mantener producción estable.

## Fase 2 — Presupuestos PDF

Objetivo:

- Crear sistema de presupuestos profesional:
  - Quote
  - QuoteItem
  - Numeración PRES-YYYY-0001
  - PDF A4
  - Botones:
    - Generar
    - Ver
    - Descargar
    - Enviar por WhatsApp

## Fase 3 — Flujo de conversión

Objetivo:

- Mejorar flujo completo:
  - Wizard → presupuesto → reserva
- Reducir fricción
- Aumentar conversión

## Fase 4 — Productos y servicios

Objetivo:

- Mejorar catálogo
- Mejorar presentación
- Mejorar claridad

## Fase 5 — Reserva de instalación

Objetivo:

- Hacerla más simple
- Evitar errores
- Validar fechas
- Preparar integración con ClimaPlan

## Fase 6 — Integración con ClimaPlan

Objetivo:

- Enviar datos por API o webhook
- No compartir base de datos
- Automatizar flujo operativo

## Fase 7 — Optimización

Objetivo:

- Mejorar velocidad
- Mejorar UX
- Mejorar SEO
- Mejorar conversión
